# DrivePro 🚘

## 📖 Descrição
O **DrivePro** é um aplicativo desenvolvido para conectar alunos em processo de obtenção da primeira CNH (Carteira Nacional de Habilitação) com instrutores autônomos cadastrados na plataforma.  
A proposta é oferecer uma experiência mais acessível, flexível e personalizada para quem está começando sua jornada como condutor.

---

## 🚀 Funcionalidades
- Cadastro de alunos e instrutores
- Busca por instrutores disponíveis na região
- Agendamento de aulas práticas
- Avaliação de instrutores
- Sistema de notificações e lembretes
- Chat integrado para comunicação direta

---

## 🛠️ Tecnologias Utilizadas
- **Kotlin** – Linguagem principal para desenvolvimento Android
- **Firebase** – Autenticação, banco de dados e notificações
- **Google Maps API** – Localização e busca por instrutores
- **Material Design** – Interface moderna e responsiva
- **Git/GitHub** – Controle de versão e colaboração
